# AI Tools for Sourcing

## 原材料行情监测工作台

[打开在线工作台](https://heyvaleriel.github.io/AI_tools_for_sourcing/) · [作品集项目01](https://valerielai.com/project-01-zh.html)

铝、铜、钢材的月度价格、供需分析与采购行动建议。使用公开来源的人工核验月度快照；不是实时行情接口。

### 网站维护

站点入口 `index.html`，公开数据位于 `data/`，地图位于 `assets/`。无需构建或服务端。更新相应 JSON 后提交到 `main`，GitHub Pages 会自动发布。

GitHub Settings → Pages → Deploy from a branch → main / (root)。
